# AsyncOS - Kikun's Journey

> 探索操作系统内核与异步编程的创新之路

## 简介

本项目是 OS Training Camp 2026 的学习与实践仓库，记录操作系统内核开发历程以及异步编程范式的探索。

## 项目目标

- **短期目标**：平稳通过 OS 比赛初赛，做好决赛准备；完成训练营基础任务并补完文档
- **长期愿景**：以合格以上成绩完成训练营，争取实习机会；在异步 OS 方向上做出创新

## 当前进展

- 🚧 **调研中**：内核方案选型（从零开发 vs 基于 ArceOS/StarryOS 改进）
